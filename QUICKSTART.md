# ⚡ Quick Start Guide

## 🚀 Get Started in 5 Minutes!

### Step 1: Install Dependencies
```bash
npm install
```

### Step 2: Run the Application
```bash
npm start
```

### Step 3: Enter Your Discord Token
When prompted, enter your Discord user token (not bot token).

### Step 4: Start Cloning!
Select option 1, 2, or 3 from the menu to begin cloning.

---

## 🗄️ Backup Location

All backups are saved to:
```
cloner/
├── active/      # Active backups
├── archive/     # Archived backups
└── metadata.json # Backup database
```
